# John-Balls
Vercel site for my Amigo that does not know how to code.

# Setup
Redirect service for my Amigo
Get a vercel account, link it to your github.
Go into index.html replace the template example.com with your site.
Keep doing this every time your site link changes.
After replacing it, press the Change File button. (Or type into the terminal git add . then git commit -m "yourcommit" and then git push if you're in a github codespace.)
then publish your site to vercel and make the name, Tehh End!
# Optional
If you have changed your site's button to something different, go into media and upload your button's png. (usually button.png)
This allows for people to not have the hassle to always ask you for your site when it changes.
